# Nikita Lopatenko — personal site

Student personal site for LinkedIn, applications, and a simple public home page.

## Run locally

```bash
cd personal-site
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy (easy options)

- **Vercel / Netlify:** import this folder, build command `npm run build`, output `dist`
- **GitHub Pages:** publish `dist` after build

Update email / LinkedIn / GitHub links in `index.html` if they change.
