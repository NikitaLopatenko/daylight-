# Nikita Lopatenko — personal site

Student personal site for LinkedIn, applications, and a simple public home page.

**Live demo (GitHub Pages):** https://nikitalopatenko.github.io/daylight-/

## Run locally

```bash
cd personal-site
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

Deploy is automatic on push to `main` (see `.github/workflows/deploy-site.yml`).
Later custom domain (`nikitalopatenko.com`, etc.) can point at the same Pages site.
